03 A CLEARER PROCESS

From file to informed judgment.

Authenticity checks work best when technical signals are combined with context and independent verification.

01 / INPUT↥

Provide the media

Select an image, video, or audio file. The interface validates the file type and size before analysis.

02 / INSPECT⌕

Examine signals

A connected model can inspect artifacts, inconsistencies, and patterns associated with synthetic media.

03 / INTERPRET↗

Review the evidence

Read model outputs alongside source provenance and independent evidence. No detector is perfectly reliable.

!
Detection is a signal, not a verdict.

AI detectors can produce false positives and false negatives. This website's initial version is an interface demonstration only; real detection requires a configured model service. Never use an automated score as the sole basis for a high-impact decision.
